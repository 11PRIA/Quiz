# Simple Quiz App

A clean and interactive web-based quiz application built with vanilla JavaScript, HTML, and CSS.

## 🎯 Features

- **Interactive Quiz Interface**: Multiple choice questions with immediate feedback
- **Score Tracking**: Real-time score calculation and display
- **Visual Feedback**: Color-coded correct/incorrect answers
- **Responsive Design**: Works on desktop and mobile devices
- **Play Again**: Option to restart the quiz after completion
- **Smooth Animations**: Hover effects and transitions for better UX

## 🚀 How to Use

1. **Open the Application**: Simply open `index.html` in your web browser
2. **Start the Quiz**: The quiz begins automatically when the page loads
3. **Answer Questions**: Click on your chosen answer from the four options
4. **Get Feedback**: See immediate visual feedback (green for correct, red for incorrect)
5. **Continue**: Click "Next" to proceed to the following question
6. **View Results**: See your final score at the end
7. **Play Again**: Click "Play Again" to restart the quiz
